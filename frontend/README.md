# Frontend

Next.js 16 (App Router, TypeScript) client for the Fireflies clone. See the [root README](../README.md) for setup, architecture and the API.

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:8000/api/v1
npm run dev                  # http://localhost:3000
npm test && npm run lint && npm run typecheck
```
